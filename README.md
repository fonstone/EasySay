# 清述 · 口才陪练

一个可以直接在微信开发者工具里跑起来的原生小程序 Demo。冷白 + 墨绿的克制视觉，围绕「开口前有结构，开口后有反馈」搭建：

**今日打卡 · 六大练习方向 · 确定性评分 · 教练点评 · 思维训练 · 普通话纠音 · 高效能复盘 · AI 私教 · 闯关课程 · 能力雷达 · 录音档案 · 金句墙 · 会员额度**

> 本项目依据公开的产品拆解文档实现，是一个**纯本地演示版**，与 Clearsay 清述官方无关。没有后端、没有 API Key、没有真实支付，导入即可运行。

---

## 一、怎么跑起来

### 环境

- 微信开发者工具（稳定版即可）
- 基础库 2.20.0 以上（推荐 3.x）

### 步骤

1. 打开微信开发者工具，选择「导入项目」。
2. 目录选择本文件夹：`D:\00 Work\clearsay`。
3. AppID 可以直接使用「测试号」；`project.config.json` 里已写入 `touristappid`。如果你有自己的小程序 AppID，替换即可。
4. 点击编译。首次进入会看到 3 步引导：选目标 → 选水平 → 选每日时长。
5. 进入「今日」，点「开始今天的练习」；允许麦克风权限后，构思倒计时结束会自动开始录音。
6. 说完点「说完了」。几秒后进入点评报告。

> **录音测试建议**：开发者工具模拟器的麦克风能力因版本而异，建议点「预览」用真机扫码测试录音与回听。若麦克风无声，先检查系统权限，再检查小程序右上角「··· - 设置 - 麦克风」。

## 二、已经实现的功能

### 1. 今日

- 每天固定一道「今日一练」，跨天自动轮换，同一天固定。
- 构思倒计时（默认 30 秒，可在设置里改成 15 / 30 / 45 秒），时间到自动开录。
- 真实录音：16kHz / 单声道 / PCM；说满目标时长、自动停止；说完可回听。
- **机会限制**：今日挑战默认 2 次机会，每开录一次消耗一次。用完提示「明天再来」，模拟真实发言压力。
- 连续打卡、7 天打卡条、今日清单（练习 / 思维题 / 朗读）、本周数据。
- 今日完成后直接显示分数，可进入完整点评。

### 2. 练习：六个抽屉

| 方向 | 练什么 | 题量 |
| --- | --- | --- |
| 美文朗读 | 语感、停顿、气息、句尾（含示范音频） | 8 篇 |
| 述思用共读 | 读懂 → 用自己的话说出来 | 8 篇 |
| 故事复述 | 人物、冲突、转折、启示 | 8 篇 |
| 随机话题 | 临场组织语言，防卡壳 | 8 题 |
| 结构表达 | 观点—理由—例子—收尾 | 8 题 |
| 场景对练 | 汇报、拒绝、面试、降温 | 8 题 |

- 每个方向 4 个难度：入门 / 初阶 / 进阶 / 高阶，每关 2 题。
- 完成任意 1 题解锁下一关，进度本地保存。
- 支持「随机一题」，也可以从私教计划直接进入。

### 3. 确定性评分引擎

没有把打分丢给大模型。分数全部由可复现的本地代码计算，**同一段录音、同一段文字，永远得到同一个分**。

**声音侧（真实 PCM 分析）**

- 帧级 RMS 能量、噪声底估计、语音段合并。
- 有效发声比例、停顿次数、长停顿（>1.5 秒）位置与时长、音量起伏、完成度。
- 无文字稿时只评 4 个可测维度：流畅、节奏、声音、完成度。
- **不假装能给内容打分**。想评内容，需要补文字稿。

**文字侧（可选文字稿）**

- 中文字数、语速（字/分钟）、口头禅密度、用词丰富度。
- 开场 / 过渡 / 收尾信号词。
- 题目要点的关键词覆盖。
- 有文字稿时升级为 7 维：内容、结构、流畅、节奏、用词、声音、完成度。

**教练点评**

- 先引用证据，再下判断：原话片段、长停顿时间点、口头禅次数。
- 最多 2 条做得好的、最多 2 条待改进、1 个「下次只练这一件事」。
- 没有明显缺点时宁少不多，不编造用户没说过的话。
- 分数与点评都保存在本机，可随时回看。

### 4. 发现

- **普通话纠音**：声母 / 韵母 / 绕口令共 15 个练习，包含发音位置、例词、三遍法、目标。每个练习带一段**合成语音示范**（Edge TTS 生成，仅用于听字音与节奏）。
- **锤炼思考力**：20 道选择题，覆盖事实/观点/猜测、结构判断、论证漏洞、类比思维。答完立即解析，记录正确率。
- **高效能复盘**：练了什么 → 卡在哪里 → 下次只改一件什么事 → 给今天的自己一句话。可翻历史。
- **AI 私教**：6 个目标（职场汇报 / 面试 / 拒绝与边界 / 社交破冰 / 亲密关系 / 即兴发言），每个目标 7 天计划，按天解锁。计划由本地选题规则生成，不联网。

### 5. 课程

- 3 条学习线：认知篇、当众表达、脱稿表达。
- 共 12 节课，每节 5 分钟左右，含 3 个小节、一句带走的话、一个「学完即练」。
- 学完可直接跳到对应练习；练习完成后自动标记课程完成。

### 6. 我的

- 能力雷达（Canvas 实时绘制，4–6 个维度，随练习增长）。
- 累计开口 / 累计分钟 / 最佳连续 / 思维正确率。
- 8 周打卡热力图。
- 录音档案（最多 15 条，可回听、删除、跳转点评）。
- 金句墙（86 分以上自动收集，也可手动收藏；可复制、移除）。
- 会员中心、设置、隐私说明。

### 7. 会员与额度（演示）

- 免费版：每天 5 次内容点评，思维题、朗读、跟读不占额度。
- 7 天体验会员：一次性领取，送 3 次点数。
- 价格梯度：38 元 / 年、48 元 / 两年、97 元 / 永久。
- **全部为本地模拟**：不会调用微信支付，不会扣款；正式上线前需按微信虚拟支付规则接入。
- 演示版不锁课程与私教，会员价值集中在无限点评；正式版可按运营策略给课程/私教加会员门槛。

### 8. 数据与隐私

- 录音、文字稿、练习记录、金句全部存在微信本地存储 / `USER_DATA_PATH`。
- 不申请通讯录、位置、相册等无关权限。
- 录音只保留最近 15 条，可逐条删除；设置里可清空练习数据或重置全部数据。
- 详见小程序内「隐私与录音说明」。

## 四、测试与自检

```bash
node tests/scoring.test.js    # 28 项：PCM、文本、评分、点评、聚合
node tests/data.test.js       # 14 项：题库、课程、思维题、纠音、私教
node tests/store.test.js      # 30 项：打卡、额度、进度、档案、会员
node tests/pages.smoke.js     # 23 个页面生命周期 + 12 个交互 + 数据绑定检查
node tests/session.flow.js    # 端到端：录音 → PCM → 评分 → 报告 → 档案
node tests/check-wxml.js      # 27 个 WXML：标签配对、花括号、空表达式
node tests/run-all.js         # 一次跑完
```

WXML / WXSS 已用官方 `wcc` / `wcsc` 编译器（`miniprogram-compiler`）全量编译通过：27 个 WXML、28 个 WXSS 无语法错误。

评分引擎测试使用合成 PCM（带静音段与音量起伏），验证：

- 有效发声、长停顿、波形采样点；
- 纯静音不误判人声；
- 文字稿结构信号、要点覆盖、口头禅；
- 同一输入分数可复现；
- 口头禅多 + 时长不足会显著扣分；
- 无文字稿时不出现内容维度；
- 能力雷达聚合。

## 五、这是演示版：和生产版的边界

| 能力 | 当前实现 | 生产建议 |
| --- | --- | --- |
| 语音识别 | 不做 ASR；文字稿由用户补充（可用输入法语音输入） | 腾讯云一句话识别 / 实时 WSS；注意 8k/16k 对齐、保留语气词 |
| 内容点评 | 本地规则 + 原话引用 | 可选大模型，只做语义判断；Schema 约束 + 证据引用 + `needs_human_review` |
| 评分 | 确定性代码，可复现 | 保留确定性打底，LLM 不参与算分 |
| 示范音频 | Edge TTS 合成，纠音模块与美文朗读有 | 真人教练录音，按字词切分，支持跟读对比 |
| 数据 | 微信本地存储 | 云数据库 / PostgreSQL + COS 私有读 + 临时链接 |
| 登录 | 无 | 微信登录 + 匿名设备号迁移 |
| 支付 | 本地模拟 | 微信支付 + 虚拟支付类目规则 + 退款 |
| 订阅消息 | 未实现 | 完成练习后静默请求一次性订阅，额度累加，6 小时节流 |
| 留存分析 | 无 | 埋点：开口率、完播率、7 日留存、付费转化 |

### 已知限制（演示版有意保留）

- 录音分析与评分是本地规则，不是专业声学评测；不评价口音、音色、方言。
- 普通话纠音与美文朗读的示范音频为合成语音，不等同于真人示范。
- 评分和点评不构成医疗、心理、法律或职业建议。
- 会员状态、价格、体验流程均为本地演示，不产生真实交易。
- 没有云端同步，卸载小程序或清理微信缓存后本地数据会丢失。
- 开发者工具模拟器的录音能力有限，录音/回听请以真机预览为准。

## 六、视觉系统

- **底色**：冷白 `#F4F7F5`，比纯白更安静，长时间看不刺眼。
- **主色**：墨绿 `#143D31 / #1B5A47 / #2F7B63`，用于主按钮、深色卡片和重点。
- **点缀**：黄铜 `#B68A4E`，只给「下次只练这一件事」、金句、停顿等少量重点。
- **文字**：墨色 `#16211D`，次级 `#74827C`。
- **字体**：大标题用宋体（Songti SC / STSong / Noto Serif SC），正文用系统无衬线；在微信里形成「纸感 + 工具感」的对比。
- **圆角**：卡片 28rpx，深色大卡 40rpx，按钮全圆。
- **节奏**：大量留白，信息按「一句标题 + 一组事实 + 一个动作」排列，避免仪表盘式的拥挤。

## 八、下一步可以做什么

1. 接腾讯云 ASR，把「补充文字稿」变成可选的增强项，而不是必需项。
2. 用 Schema 约束接一个大模型做语义点评，但保留确定性评分与证据引用约束。
3. 把录音、报告、课程进度迁到云端，做跨设备同步。
4. 接入微信支付、订阅消息、激励视频，跑通 38 元 / 年卡模型。
5. 做真机声学标定：不同机型的麦克风增益差异很大，需要按设备归一化音量特征。
6. 增加「跟读对比」：示范音频 + 用户录音逐句对齐，标出吞字与错音。
7. 增加分享卡片与小红书笔记素材，把「金句墙」做成可分享的图片。
