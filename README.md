# 清述 · 口才陪练

一个可以直接在微信开发者工具里跑起来的原生小程序 Demo。冷白 + 墨绿的克制视觉，围绕「开口前有结构，开口后有反馈」搭建：

**今日打卡 · 六大练习方向 · 确定性评分 · 教练点评 · 思维训练 · 普通话纠音 · 高效能复盘 · 私教计划 · 闯关课程 · 能力雷达 · 录音档案 · 金句墙 · 会员额度**

> 本项目依据公开的产品拆解文档实现，是一个**纯本地演示版**，与 Clearsay 清述官方无关。没有后端、没有 API Key、没有真实支付，导入即可运行。

---

## 一、怎么跑起来

### 环境

- 微信开发者工具（稳定版即可）
- 基础库 2.20.0 以上（推荐 3.x）

### 步骤

1. 打开微信开发者工具，选择「导入项目」。
2. 目录选择本文件夹：`D:\00 Work\clearsay`。
3. AppID 可以直接使用「测试号」；`project.config.json` 里已写入 `touristappid`。如果你有自己的小程序 AppID，替换即可。
4. 点击编译。首次进入会看到 3 步引导：选目标 → 选水平 → 选每日时长。
5. 进入「今日」，点「开始今天的练习」；允许麦克风权限后，构思倒计时结束会自动开始录音。
6. 说完点「说完了」。几秒后进入点评报告。

> **录音测试建议**：开发者工具模拟器的麦克风能力因版本而异，建议点「预览」用真机扫码测试录音与回听。若麦克风无声，先检查系统权限，再检查小程序右上角「··· - 设置 - 麦克风」。

> **设计评审预览**：直接用浏览器打开 `preview/index.html`。它是自包含的高保真评审页，不属于小程序运行包，也不会随小程序上传。

## 二、已经实现的功能

### 1. 今日

- 每天固定一道「今日一练」，跨天自动轮换，同一天固定。
- 构思倒计时（默认 30 秒，可在设置里改成 15 / 30 / 45 秒），时间到自动开录。
- 真实录音：16kHz / 单声道 / PCM；说满目标时长、自动停止；说完可回听。
- **机会限制**：今日挑战默认 2 次机会，每开录一次消耗一次。用完提示「明天再来」，模拟真实发言压力。
- 连续打卡、7 天打卡条、今日清单（练习 / 思维题 / 朗读）、本周数据。
- 今日完成后直接显示分数，可进入完整点评。

### 2. 练习：六个抽屉

| 方向 | 练什么 | 题量 |
| --- | --- | --- |
| 美文朗读 | 语感、停顿、气息、句尾（含示范音频） | 8 篇 |
| 述思用共读 | 读懂 → 用自己的话说出来 | 8 篇 |
| 故事复述 | 人物、冲突、转折、启示 | 8 篇 |
| 随机话题 | 临场组织语言，防卡壳 | 8 题 |
| 结构表达 | 观点—理由—例子—收尾 | 8 题 |
| 场景对练 | 汇报、拒绝、面试、降温 | 8 题 |

- 每个方向 4 个难度：入门 / 初阶 / 进阶 / 高阶，每关 2 题。
- 完成任意 1 题解锁下一关，进度本地保存。
- 支持「随机一题」，也可以从私教计划直接进入。
- **找题**：关键词与场景同义词搜索、方向/关卡筛选、收藏筛选、推荐/最近/最短/最高难度排序、搜索历史、收藏星标与最近练过。
- 收藏贯通练习首页、分类详情、点评报告和「我的」，下次不用再翻六个抽屉。

### 3. 确定性评分引擎

没有把打分丢给大模型。分数全部由可复现的本地代码计算，**同一段录音、同一段文字，永远得到同一个分**。

**声音侧（真实 PCM 分析）**

- 帧级 RMS 能量、噪声底估计、语音段合并。
- 有效发声比例、停顿次数、长停顿（>1.5 秒）位置与时长、音量起伏、完成度。
- 无文字稿时只评 4 个可测维度：流畅、节奏、声音、完成度。
- **不假装能给内容打分**。想评内容，需要补文字稿。

**文字侧（自述稿，不是语音识别结果）**

- 本版本**没有 ASR**。文字稿由用户在报告页凭记忆补写，正名为「自述稿」；`utils/asr.js` 做能力探测，配置 `file` 模式转写提供者后可在练习当次自动带稿，未配置时明确返回「未接入」。
- 中文字数、语速（字/分钟）、口头禅密度、用词丰富度、开场 / 过渡 / 收尾信号词、题目要点覆盖。
- 有自述稿时升级为 7 维：内容、结构、流畅、节奏、用词、声音、完成度。
- 每个维度带 `source` / `basis`，报告页「数据来源」卡可核对来自录音还是自述稿。
- 用 VAD 得到的**有效发声秒数**推算预期字数，做一次音文一致性校验：自述稿明显偏长或偏短时提示内容维度仅供参考，不假装两者天然一致。
- 自述稿与录音指纹 `audioKey` 绑定，每份报告只能补写一次，声音维度不会被改写。

**可解释规则点评（不是 AI 生成）**

- 先引用证据，再下判断：自述稿原话片段、长停顿时间点、口头禅次数。
- 每条建议都带 `ruleId`、触发条件、实测值、阈值，报告页可逐条展开「为什么这么说」。
- 最多 2 条做得好的、最多 2 条待改进、1 个「下次只练这一件事」，并说明取的是本次最低分维度。
- 没有明显缺点时宁少不多，不编造用户没说过的话。

**真实反馈，不做动画**

- 录音页波形来自 `RecorderManager.onFrameRecorded` 的真实 PCM 帧 → RMS → 24 柱；没有音频帧时保持静音并提示「等待音频帧」，不再画 `Math.sin` 假曲线。
- 分析进度由 `utils/analysis.js` 的 6 个真实阶段驱动（读取 / 分帧 / VAD / 停顿 / 组装 / 落库），页面显示各阶段本机实测毫秒数；定时器伪装进度已删除。

### 4. 发现

- **普通话纠音**：声母 / 韵母 / 绕口令共 15 个练习，包含发音位置、例词、三遍法、目标。每个练习带一段**合成语音示范**（Edge TTS 生成，仅用于听字音与节奏）。
- **锤炼思考力**：20 道选择题，覆盖事实/观点/猜测、结构判断、论证漏洞、类比思维。答完立即解析，记录正确率。
- **高效能复盘**：练了什么 → 卡在哪里 → 下次只改一件什么事 → 给今天的自己一句话。可翻历史。
- **私教计划**：6 个目标（职场汇报 / 面试 / 拒绝与边界 / 社交破冰 / 亲密关系 / 即兴发言）。`utils/plan.js` 按最近报告最薄弱的维度、目标方向、练习量、收藏 / 最近 / 已练题目动态排 7 天，每题带一句「为什么排这道题」，可随时按最新数据重排；旧版固定课表自动兼容。不联网、不调用模型。

### 5. 课程

- 3 条学习线：认知篇、当众表达、脱稿表达。
- 共 12 节课，每节 5 分钟左右，含 3 个小节、一句带走的话、一个「学完即练」。
- 学完可直接跳到对应练习；练习完成后自动标记课程完成。

### 6. 我的

- 能力雷达（Canvas 实时绘制，4–6 个维度，随练习增长）。
- 累计开口 / 累计分钟 / 最佳连续 / 思维正确率。
- 8 周打卡热力图。
- 录音档案（最多 15 条，可回听、删除、跳转点评）。
- 金句墙（86 分以上自动收集，也可手动收藏；可复制、移除）。
- 会员中心、设置、隐私说明。

### 7. 会员与额度（纯本地演示）

- 免费版：每天 5 次完整点评，思维题、朗读、跟读不占额度。
- 本机体验开关：可打开 7 天体验或不限次模式，只影响本地额度。
- 页面上的 38 / 48 / 97 元**只是正式版价格示意**：会员页顶部固定「本地演示 · 不收款」横幅，按钮为「开启本地体验」，弹窗与页脚明确不调用微信支付、不生成订单、不扣款。
- `store.getEntitlement()` 是权益单一真源，返回 `source: 'local-demo'` / `isRealPayment: false`；演示版不锁课程与私教。
- 正式上线需按微信虚拟支付类目规则接入支付，并由服务端校验订单、支持退款与到期降级。

### 8. 数据与隐私

- 录音、自述稿、练习记录、金句全部存在微信本地存储 / `USER_DATA_PATH`，共 19 个 `cs_*` 键。
- 不申请通讯录、位置、相册等无关权限。
- 录音只保留最近 15 条，可逐条删除；设置里可清空练习数据或重置全部数据。
- **备份三通道**：导出真实 `.json` 文件到 `USER_DATA_PATH` → 支持时 `wx.shareFile` 分享 → 剪贴板兜底；`cs_backup_meta` 记录上次备份时间，距上次超过 7 天或新增 3 份报告即在设置页提醒。
- 从剪贴板恢复备份，覆盖同名数据；录音文件本身不导出。
- **没有云同步**：卸载小程序或清理微信缓存会丢掉全部记录，导出文件是唯一保全方式，页面内已明确告知。
- 启动时自动执行 `SCHEMA_VERSION=4` 迁移与一致性修复，清理悬空历史、失效音频引用和超限报告。
- 详见小程序内「隐私与录音说明」。

### 本轮「伪实现」治理对照

| 截图里的原判断 | 现在的落地 |
| --- | --- |
| 缺失 ASR | 能力探测 + 可插拔转写接口；未配置时 UI 明确「未接入」，绝不把人工自述稿说成识别结果 |
| 内容评分与音频脱钩 | 维度带 `source`；VAD 有效发声秒数推算预期字数做一致性校验；`audioKey` 锁定一次 |
| 教练点评是模板、非 AI | 改为可解释规则引擎，逐条展示触发条件 / 实测值 / 阈值，全站去掉 AI 字样 |
| 分析进度是装饰性 | 真实计算阶段 + 实测毫秒数，删掉 480ms 定时器与 1.6s 假等待 |
| 录音页是假波形 | `onFrameRecorded` 真实 PCM 帧 → RMS；无帧保持静音，删除 `Math.sin` 与 CSS 动画 |
| 私教是固定课表 | 按薄弱维度 / 目标 / 练习量动态排题，每题带理由，可重排 |
| 会员支付是模拟 | 顶部不收款横幅 + 价格示意 + 本地演示开关 + `getEntitlement()` 单一口径 |
| 卸载即丢 | 文件备份 + 分享 + 剪贴板 + 备份提醒 + 页面明确告知「无云同步」 |

### 已知限制（演示版有意保留）

- 录音分析与评分是本地规则，不是专业声学评测；不评价口音、音色、方言。
- 普通话纠音与美文朗读的示范音频为合成语音，页面已标注「合成示范」，不等同于真人录音。
- **没有 ASR**：内容 / 结构 / 用词只分析用户手动补写的自述稿，程序并没有听懂录音内容；`utils/asr.js` 已预留可插拔转写接口。
- **教练点评是本地可解释规则引擎，不是 AI 生成**；每条建议都带触发条件与实测值。
- 评分和点评不构成医疗、心理、法律或职业建议。
- 会员状态、价格、体验流程均为本地演示开关，不产生真实交易；页面已显性披露「不收款」。
- 没有云端同步，卸载小程序或清理微信缓存后本地数据会丢失；设置页提供 `.json` 文件备份与提醒。
- 开发者工具模拟器的录音能力有限，`onFrameRecorded` / 录音 / 回听请以真机预览为准。

## 六、视觉系统

- **底色**：冷白 `#F4F7F5`，比纯白更安静，长时间看不刺眼。
- **主色**：墨绿 `#143D31 / #1B5A47 / #2F7B63`，用于主按钮、深色卡片和重点。
- **点缀**：黄铜 `#B68A4E`，只给「下次只练这一件事」、金句、停顿等少量重点。
- **文字**：墨色 `#16211D`，次级 `#74827C`。
- **字体**：大标题用宋体（Songti SC / STSong / Noto Serif SC），正文用系统无衬线；在微信里形成「纸感 + 工具感」的对比。
- **圆角**：卡片 28rpx，深色大卡 40rpx，按钮全圆。
- **节奏**：大量留白，信息按「一句标题 + 一组事实 + 一个动作」排列，避免仪表盘式的拥挤。
